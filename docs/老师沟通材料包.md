## 二、发给郭老师

郭老师您好，AudioLab 的专家评分字段已经补充完成。后续请您重点协助确认各声源的标准化听感问题标签，并使用系统真实试听后评分，不生成随机分数。

当前评分流程为：选择待评估声源，试听分离结果，在 0—100 量表上填写质量、干扰抑制、伪影控制和整体可接受度；如果发现问题，填写问题起止时间，并从该声源的标准标签中选择对应标签；如标准标签无法覆盖，可增加本次评分专用的自定义标签；最后填写主观可靠性。

1. Vocals、Drums、Bass、Other 各自的标签是否准确、是否需要增删或改名；

3. 哪些问题需要标注起止时间，哪些问题属于整段 15 秒片段问题；
4. 评分量表和可靠性定义是否符合您的听感判断。

### 建议发送的材料

- 不发送算法真实名称给评分人。管理员先生成盲化样本，再由专家使用盲化样本入口试听和评分。

## 三、专家评分字段说明

| 字段 | 填写要求 |
|---|---|
| 质量 | 0—100，目标声源音质与金标准的接近程度 |
| 干扰抑制 | 0—100，非目标声源残留越少分数越高 |
| 伪影控制 | 0—100，水声、机械声、颗粒感等算法伪影越少分数越高 |
| 整体可接受度 | 0—100，对该 15 秒片段作为可用结果的总体判断 |
| 问题起止时间 | 0—15 秒，开始时间必须早于结束时间 |
| 标准化标签 | 从当前声源对应的标签集中选择，可多选 |
| 自定义标签 | 仅描述本次评分的新问题，不直接修改标准标签库 |
| 主观可靠性 | 0—100，表示本次判断的把握程度 |
