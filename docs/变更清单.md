## 核心改进

### 1. 完整 BSS Eval v3 实现

**公式**:
```
ŝ = s + e_spat + e_interf + e_artif

SDR = 10 log10(||s||² / ||e_spat + e_interf + e_artif||²)
SIR = 10 log10(||s + e_spat||² / ||e_interf||²)
SAR = 10 log10(||s + e_spat + e_interf||² / ||e_artif||²)
ISR = 10 log10(||s||² / ||e_spat||²)
```

**关键实现**:
- 投影算子：单向量投影 + 多向量最小二乘
- 误差分解：空间失真、干扰、伪影
- 支持2-4个源同时评估

### 2. 批量主观评分

**要求**:
- 必须同时提交 Vocals, Drums, Bass, Other 四个源
- 每个源3个维度：quality, interference, artifacts
- 自动验证完整性

**优点**:
- 避免遗漏评分
- 减少网络请求
- 保证数据一致性
- 防止重复提交
