# 评分流程测试指南

## 功能概述

本次更新实现了以下功能：
1. 前端只需选择混合音频（Mixture），系统自动加载配套的标准音源（Gold Standard）
2. 切换不同的stem时，自动切换对应的gold标准音源
3. 必须完成所有stem的所有指标评分才能提交

## 测试步骤

### 1. 准备测试数据

确保音频资源库中有成组的音频资源，命名格式如下：
- `SongName [Mixture]` - 混合音频
- `SongName [Gold Vocals]` - 人声标准音源
- `SongName [Gold Drums]` - 鼓声标准音源
- `SongName [Gold Bass]` - 贝斯标准音源
- `SongName [Gold Other]` - 其他乐器标准音源

### 2. 测试自动加载Gold音源

1. 登录系统（专家账号）
2. 在"1. Input Source"区域点击"从音频资源库选择"
3. 选择一个Mixture音频（例如：`TestSong [Mixture]`）
4. 系统应该：
   - 成功加载混合音频
   - 自动在后台下载所有对应的Gold音源
   - 显示成功消息，例如："已自动加载 4 个配套的Gold Standard音源"

### 3. 测试自动切换Gold音源

1. 选择一个算法并完成音频分离
2. 在"4. Stem Source"区域选择不同的stem（Vocals/Drums/Bass/Other）
3. 每次切换stem时，系统应该：
   - 自动加载对应的gold标准音源
   - 更新"2. Gold Standard"区域的显示
   - 更新可视化对比图

### 4. 测试评分完整性验证

1. 完成音频分离后，进入评分界面
2. 观察评分表单：
   - 应该显示4个stem卡片（Vocals, Drums, Bass, Other）
   - 每个卡片显示3个评分维度（质量、干扰抑制、伪影抑制）
   - 顶部显示完成进度条和进度文字

3. 测试部分评分：
   - 只为部分stem评分（例如只评Vocals和Drums）
   - 提交按钮应该显示为禁用状态
   - 按钮文字显示："请完成所有评分 (2/4)"
   - 未完成的stem卡片应该有橙色边框

4. 测试完整评分：
   - 为所有4个stem的所有3个维度评分
   - 完成的stem卡片应该显示绿色边框和✓图标
   - 进度条应该显示100%
   - 提交按钮变为可用状态，文字显示："提交所有评分"

5. 测试提交：
   - 点击提交按钮
   - 系统应该成功提交所有评分
   - 显示成功消息

## 预期结果

### 后端API

新增接口：`GET /api/audio/resources/bundle/gold-stems?bundle_title={title}`

返回格式：
```json
{
  "vocals": { "id": "123", "title": "SongName [Gold Vocals]", ... },
  "drums": { "id": "124", "title": "SongName [Gold Drums]", ... },
  "bass": { "id": "125", "title": "SongName [Gold Bass]", ... },
  "other": { "id": "126", "title": "SongName [Gold Other]", ... }
}
```

### 前端行为

1. **自动加载**：选择Mixture后，自动下载所有gold stems到内存
2. **自动切换**：切换stem时，自动从内存加载对应的gold音源
3. **进度提示**：实时显示评分完成进度（x/4）
4. **视觉反馈**：
   - 未完成的stem：橙色边框
   - 已完成的stem：绿色边框 + ✓图标
   - 进度条：动态显示完成百分比
5. **提交控制**：只有所有评分完成后才能提交

## 常见问题

### Q: 如果某个gold音源不存在怎么办？
A: 系统会跳过不存在的gold音源，只加载可用的。用户仍然可以手动选择gold音源。

### Q: 如果用户手动选择了不同的gold音源？
A: 手动选择会覆盖自动加载的gold音源。

### Q: 评分时可以修改已填写的分数吗？
A: 可以，在提交前可以随时修改任何评分。

### Q: 如果中途切换了mixture音频？
A: 系统会重新加载新的gold stems，之前的评分会被清空。

## 技术细节

### 前端状态管理

```javascript
// 存储所有gold stems的资源信息
const [goldStems, setGoldStems] = useState({
  vocals: null,
  drums: null,
  bass: null,
  other: null
});

// 存储所有gold stems的文件对象
const goldStemFilesRef = useRef({
  vocals: null,
  drums: null,
  bass: null,
  other: null
});
```

### 关键函数

1. `handleResourceSelect` - 处理mixture选择，自动加载gold stems
2. `handleStemChange` - 处理stem切换，自动切换gold音源
3. `validateScores` - 验证所有评分是否完整
4. `isStemComplete` - 检查单个stem是否完成评分
