# 多源分离指标计算指南

## 概述

项目现在支持两种客观指标计算方式：

### 1. 两源假设（原有方式）
- **适用场景**：只关心单个目标源的分离质量
- **需要**：上传1个金标准参考
- **接口**：`POST /api/tasks/{task_id}/objective-metrics`
- **公式**：`mixture = target + interference`

### 2. 多源分离（新增方式）✨
- **适用场景**：有完整数据集，需要同时评估所有源
- **需要**：上传2-4个金标准参考
- **接口**：`POST /api/tasks/{task_id}/objective-metrics-batch`
- **公式**：完整 BSS Eval v3（考虑源间干扰）

## 使用方法

### 方式一：单源评估（两源假设）

```bash
curl -X POST "http://localhost:8000/api/tasks/123/objective-metrics?target=Vocals" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -F "reference=@vocals_reference.wav"
```

**返回示例**：
```json
{
  "target_stem": "Vocals",
  "sdr": 8.5,
  "sir": 12.1,
  "sar": 7.8,
  "comment": "已基于你上传的金标准参考 stem 计算 SDR/SIR/SAR（两源假设）"
}
```

### 方式二：多源评估（完整 BSS Eval）✨

```bash
curl -X POST "http://localhost:8000/api/tasks/123/objective-metrics-batch" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -F "vocals_ref=@vocals_reference.wav" \
  -F "drums_ref=@drums_reference.wav" \
  -F "bass_ref=@bass_reference.wav" \
  -F "other_ref=@other_reference.wav"
```

**返回示例**：
```json
{
  "task_id": 123,
  "metrics_by_source": {
    "Vocals": {
      "sdr": 8.5,
      "sir": 12.1,
      "sar": 7.8,

    },
    "Drums": {
      "sdr": 7.2,
      "sir": 10.5,
      "sar": 8.1,
      "isr": 7.2
    },
    "Bass": {
      "sdr": 6.8,
      "sir": 9.8,

      "sdr": 5.9,

    "sdr": 7.1,
```

## 指标说明

| 指标 | 全称 | 含义 | 越高越好 |
|------|------|------|---------|
| **SDR** | Signal-to-Distortion Ratio | 整体失真程度 | ✅ |
| **SIR** | Signal-to-Interference Ratio | 其他源的干扰抑制能力 | ✅ |
| **SAR** | Signal-to-Artifacts Ratio | 算法伪影抑制能力 | ✅ |
| **ISR** | Image-to-Spatial Ratio | 空间失真（单声道下等于SDR） | ✅ |

## 两种方法的区别

### 两源假设
```python
# 简化模型
mixture = target + interference
interference = mixture - target_reference

# 只考虑目标源 vs 其余所有源
```

**优点**：
- 只需1个金标准参考
- 计算快速
- 适合快速评估

**缺点**：
- 无法区分不同干扰源的影响
- 不符合多源分离的真实场景

### 多源分离（完整 BSS Eval）
```python
# 完整模型
mixture = vocals + drums + bass + other

# 对每个源：
s_target = 投影到目标源子空间
e_interf = 投影到其他源子空间 - s_target
e_artif = estimate - 投影到所有源子空间
```

**优点**：
- 准确反映多源分离场景
- 可以分析每个源的干扰贡献
- 符合学术标准（BSS Eval v3）

**缺点**：
- 需要所有源的金标准参考
- 计算稍慢

## 推荐使用场景

| 场景 | 推荐方法 |
|------|---------|
| 有完整数据集（MUSDB18等） | ✅ 多源分离 |
| 只有部分金标准 | 两源假设 |
| 快速原型验证 | 两源假设 |
| 学术论文对比 | ✅ 多源分离 |
| 生产环境评估 | 两源假设（用户难以提供完整参考） |
