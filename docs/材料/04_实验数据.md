# 实验数据

## 一、实验数据集

### 1.1 数据集基本信息

| 项目 | 内容 |
|------|------|
| **数据集名称** | MUSDB18 |
| **来源** | SIGSEP 社区标准数据集 |
| **曲目数量** | 150 首完整长度的多风格音乐曲目 |
| **总时长** | 约 10 小时 |
| **音乐风格** | 爵士、电子、摇滚、金属等多种类型 |
| **音频格式** | 44.1 kHz 采样率，立体声 |
| **数据划分** | 训练集 100 首 / 测试集 50 首 |

### 1.2 数据文件结构

每首歌曲包含以下文件：

```
歌曲名称/
├── mixture.wav      # 混合音频（所有轨道的叠加）
├── vocals.wav       # 人声参考音轨
├── drums.wav        # 鼓参考音轨
├── bass.wav         # 贝斯参考音轨
└── other.wav        # 其他伴奏参考音轨
```

### 1.3 数据集在平台中的使用

- **分离任务**：以 mixture.wav 作为输入，运行不同算法进行分离
- **客观指标计算**：以原始 stems（vocals/drums/bass/other）作为参考信号，与算法估计结果进行对比
- **主观评价**：评审员听辨分离结果并与参考音轨进行对比

## 二、评估指标体系

### 2.1 客观指标

#### BSS Eval 多源评估框架

将估计信号分解为四个分量：
$$\hat{s} = s + e_{spat} + e_{interf} + e_{artif}$$

其中：
- $s$ — 目标源信号（参考）
- $e_{spat}$ — 空间/滤波失真误差
- $e_{interf}$ — 其他源泄漏引起的干扰误差
- $e_{artif}$ — 算法引入的伪影误差

基于此定义的三个核心指标：

| 指标 | 全称 | 公式 | 衡量内容 |
|------|------|------|----------|
| **SDR** | Signal-to-Distortion Ratio | $10\log_{10}\frac{\|s\|^2}{\|e_{spat}+e_{interf}+e_{artif}\|^2}$ | 总体失真程度 |
| **SIR** | Signal-to-Interference Ratio | $10\log_{10}\frac{\|s+e_{spat}\|^2}{\|e_{interf}\|^2}$ | 声部泄漏程度 |
| **SAR** | Signal-to-Artifacts Ratio | $10\log_{10}\frac{\|s+e_{spat}+e_{interf}\|^2}{\|e_{artif}\|^2}$ | 算法伪影程度 |

#### 补充指标

| 指标 | 全称 | 特点 |
|------|------|------|
| **SI-SDR** | Scale-Invariant SDR | 对整体增益缩放不敏感，衡量重建结构差异 |
| **ISR** | Image-to-Spatial Ratio | BSS Eval v3 新增，衡量空间保真度 |

#### 辅助创新指标：WOC/SOC

| 指标 | 全称 | 公式 | 用途 |
|------|------|------|------|
| **WOC** | Waveform Overlap Consistency | $\frac{\sum_t \min(\tilde{a}(t),\tilde{\hat{a}}(t))}{\sum_t \max(\tilde{a}(t),\tilde{\hat{a}}(t))}$ | 时域重叠一致性 |
| **SOC** | Spectrogram Overlap Consistency | $\frac{\sum_{f,t}\min(\tilde{A}(f,t),\tilde{\hat{A}}(f,t))}{\sum_{f,t}\max(\tilde{A}(f,t),\tilde{\hat{A}}(f,t))}$ | 时频域重叠一致性 |

其中 $\tilde{a}(t)$、$\tilde{\hat{a}}(t)$、$\tilde{A}(f,t)$、$\tilde{\hat{A}}(f,t)$ 均为 L1 归一化后的非负幅度表示。

### 2.2 主观评价维度

| 维度 | 英文 | 评分范围 | 评价内容 |
|------|------|----------|----------|
| **音质** | Quality | 1-5 分 | 整体清晰度、保真度、自然度 |
| **干扰抑制** | Interference | 1-5 分 | 目标声部中非目标声部的残留程度 |
| **伪影控制** | Artifacts | 1-5 分 | 算法引入的非自然成分（金属音、抖动、断续） |

## 三、实验设计方案

### 3.1 客观指标对比实验

**目的**：比较四种算法在多声部音乐分离任务上的客观性能。

**实验设置**：

| 参数 | 设置 |
|------|------|
| 测试集 | MUSDB18 测试集 50 首 |
| 对比算法 | MDX23C、Demucs4HT、Band Split RoFormer、SCNet |
| 评估指标 | SDR、SIR、SAR、ISR、SI-SDR（逐 stem，四 stem 宏平均） |
| 数据格式 | 统一为单声道、44.1kHz、PCM 16bit |
| 统计汇报 | Mean ± Std |

**实验流程**：

1. 对每首测试歌曲，分别使用四种算法进行分离
2. 对每个分离结果，逐 stem 计算所有客观指标
3. 对每个算法，汇总所有 50 首歌曲的结果
4. 计算宏平均（Macro Average）作为算法整体性能
5. 以 Mean ± Std 形式汇报

### 3.2 主观评价实验

**目的**：评估四种算法分离结果的实际听感质量。

**实验设置**：

| 参数 | 设置 |
|------|------|
| 样本选择 | 从测试集随机抽取 10 首歌曲 |
| 评审员 | 5 名具有音频处理经验的专家 |
| 评价对象 | 4 种算法 × 4 个 stem（Vocals/Drums/Bass/Other） |
| 评价维度 | 音质、干扰抑制、伪影控制（1-5 分李克特量表） |
| 实验方法 | 双盲多激励听音测试（参考 MUSHRA 规范） |
| 培训 | 正式实验前统一培训，明确评分标准 |

### 3.3 主客观关联分析实验

**目的**：验证 SOC 指标与主观音质评分之间的关联。

**分析方法**：

1. **Spearman 等级相关**：计算 SOC 与 Quality 评分的 Spearman ρ，并报告显著性水平 p
2. **排列检验（Permutation Test）**：通过随机打乱 SOC 标签，构造零分布，计算单侧 p 值
3. **分组检验**：将样本按 SOC 分位区间分组，比较最低分位与最高分位的主观评分差异

### 3.4 算法间显著性检验

**目的**：判断不同算法之间的性能差异是否具有统计显著性。

**方法**：配对 Wilcoxon 符号秩检验（含正态近似、打结修正、秩双列效应量），对同一歌曲的配对样本进行检验。

## 四、原始实验数据说明

所有实验原始数据通过 AudioLab 平台数据库进行持久化存储，包括：

1. **separation_tasks 表**：每个分离任务的算法、状态、文件路径、客观指标（SDR/SIR/SAR）、元数据（JSON 含 SI-SDR/SOC 等）
2. **scores 表**：每条主观评分记录，含评分人、任务、算法、stem、三维评分值
3. **stem_files 表**：分离结果文件路径
4. **audio_resources 表**：音频资源元数据

可通过平台以下 API 端点获取和导出实验数据：
- `GET /api/tasks/stats/objective` — 客观指标汇总
- `GET /api/tasks/stats/significance` — 显著性检验结果
- `GET /api/scores/stats/detailed` — 主观评分统计
- `GET /api/scores/stats/subjective-objective-points` — 主客观联合数据
- `GET /api/scores/stats/soc-quality-correlation` — SOC-音质相关分析
- `GET /api/tasks/export/csv` — CSV 数据导出
- `GET /api/tasks/export/paper-package` — 论文数据包打包下载（ZIP）
