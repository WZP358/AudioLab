# 研发项目立项证明

## 一、项目基本信息

| 项目 | 内容 |
|------|------|
| **项目名称** | AudioLab——基于主客观协同评估的音乐源分离评测系统 |
| **项目类型** | 应用研究 / 系统开发 |
| **研发周期** | 2025年 — 至今 |
| **所属领域** | 音频信号处理、深度学习、音乐信息检索 |

---

## 二、研发动机（立项背景与问题分析）

### 2.1 核心痛点

在自研音乐源分离（Music Source Separation, MSS）算法模型的过程中，发现了以下三个关键痛点：

**痛点一：实验数据分散存储，缺乏统一管理**

每次进行音频分离实验时，需要同时管理原始混合音频（Mixture）、参考标准音轨（Gold Stems）、不同算法输出的估计结果，以及与之对应的客观指标与主观评分。这些数据分散在本地磁盘、不同工具、不同格式中，缺乏结构化组织和统一检索能力，导致实验管理效率低下，也难以保证不同实验之间数据语境的一致性。

**痛点二：主客观评估割裂，难以全面衡量算法性能**

在音乐源分离领域，传统的评估方式主要依赖客观指标（如 SDR、SIR、SAR、SI-SDR）。然而在实际研究中发现，"指标好看、听感不稳"的问题普遍存在——同一模型在不同曲风、不同编配密度下经常出现声部泄漏（source leakage）、瞬态响应模糊（transient smearing）或高频伪影（high-frequency artifacts）等感知质量问题。现有的评估工具（museval、mir_eval 等）仅支持客观指标计算，缺少与主观听感评价的结构化衔接；而主观评价又缺乏标准化的流程和平台支撑。这种割裂状态导致难以建立"模型性能—感知质量"之间的系统化理解。

**痛点三：数据可视化难，结果对比不方便**

不同算法在同一音频上的分离效果需要通过波形对比、频谱对比、残差试听等手段才能深入分析差异，但这些可视化与交互式的分析手段在现有工具中要么缺失、要么需要手工编写脚本，而无法在一个统一的平台中完成，导致对比分析效率低下。

### 2.2 现有方案不足

经过对国内外现有方案的调研，发现以下问题：

- **面向终端用户的在线分离平台**（如 LALAL.AI、Moises、MVSEP）：主要面向消费级应用场景，缺乏统一的评测标准与实验可复现机制，不支持多模型的系统化对比分析及主观评价研究。
- **开源分离工具与模型库**（如 Spleeter、Demucs、Open-Unmix）：主要聚焦算法层面，缺乏统一的任务管理与实验组织能力，难以将主观听感评价纳入标准化评测流程。
- **学术评测工具包**（如 museval、mir_eval）：具有实现规范、结果可复现的优点，但通常缺乏可视化界面及多用户协作机制，尤其不支持主观评价数据的结构化采集与分析。
- **综合评测与展示平台**：虽提供多模型评测与排行榜功能，但整体仍以客观指标为主，缺乏主客观评估融合机制。

### 2.3 立项决策

基于以上分析，决定立项开发 AudioLab 系统，将"数据准备—分离执行—结果分析—主客观评估—统计反馈"整合为统一工作流，以软件工程方法系统性地解决上述三个痛点。

## 三、研发目标

### 3.1 总体目标

构建一个面向音乐源分离模型的综合评测平台，实现以下核心能力：

1. **多模型统一管理**：在同一平台中支持多种分离算法的统一调用、参数管理与结果归档，通过统一接口屏蔽底层模型差异，保证对比实验的公平性与可复现性。
2. **主客观协同评估**：将客观指标自动计算与主观专家打分融合在统一的评测流程中，建立"客观指标—主观听感"之间的关联分析能力。
3. **结果可视化与分析**：提供波形对比、频谱对比、残差试听等交互式分析工具，以及算法横向对比、统计显著性检验、主客观相关性分析等数据化分析手段。

### 3.2 具体目标

| 目标维度 | 具体内容 |
|----------|----------|
| **算法集成** | 集成 MDX23C、Demucs4HT、Band Split RoFormer、SCNet 等代表性模型，并预留自研模型扩展接口 |
| **客观指标** | 实现 BSS Eval v3 多源评估框架（SDR/SIR/SAR/ISR），以及 SI-SDR 尺度不变指标 |
| **辅助指标** | 提出 WOC/SOC 重叠一致性指标，用于解释主客观差异 |
| **主观评价** | 建立基于 MUSHRA 规范的专家主观评分流程，涵盖音质、干扰抑制、伪影控制三个维度 |
| **统计分析** | 实现 Spearman 等级相关、Wilcoxon 符号秩检验、排列检验等统计方法，支撑主客观关联分析 |
| **平台功能** | 支持专家与管理员双角色协作，包含任务管理、资源库、通知系统、日志审计等完整功能 |

## 四、创新点

1. **主客观协同评估方法**：首次将客观指标计算、主观专家评分和主客观关联分析整合为统一的评测工作流，打通从"算法输出"到"感知质量"的完整链路。

2. **重叠一致性辅助度量（WOC/SOC）**：提出基于 L1 归一化幅度表示的重叠一致性指标（IoU-like），将"波形/频谱重叠"的可视化现象数字化，用于解释客观指标与主观听感之间的差异，并提供频带级分析（SOC_k）、相位一致性（PC）和感知加权（PSOC）等扩展模块。

3. **多引擎分离架构**：采用策略模式设计统一的分离引擎接口，支持本地 MSS 推理、远程 HTTP 模型服务、本地自定义脚本和 Mock 演示四种模式，通过环境变量灵活切换，实现"模型差异"收敛到推理模块内部的技术路线。

4. **反馈驱动迭代机制**：将专家主观评分和文本反馈作为优化信号，定向指导算法改进（如针对 SCNet 引入注意力机制与 LoRA 微调策略），形成"评测—反馈—优化—再评测"的闭环。

1. 一套完整可运行的 AudioLab 评测平台软件系统

3. WOC/SOC 辅助度量指标的定义、算法实现与实验验证
4. 学术论文与专利
