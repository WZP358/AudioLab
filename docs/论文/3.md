	音乐源分离（Music Source Separation, MSS）旨在将混合音频解耦为若干具有语义意义的独立声部（如 Vocals、Drums、Bass 与 Other）。随着深度学习在时频建模与表示学习方面的进展，基于公开数据集的客观评估指标（如 SDR、SI-SDR 等）持续提升，使得 MSS 在智能编曲、音频编辑、音乐信息检索与音乐教育等场景中具备了广泛应用前景。然而，在实际部署与用户体验层面，一个长期存在的现象是：客观指标的提升并不总能对应稳定的感知质量。具体而言，模型可能在不同曲风与编配密度下出现声部泄漏（source leakage）、瞬态响应模糊（transient smearing）以及高频伪影（high-frequency artifacts）等问题，从而造成“指标好看但听感不稳”的评价落差。该矛盾提示：若仅依赖单一客观指标，往往难以充分刻画模型在真实使用中对听感质量的综合影响。

​	围绕 MSS 的应用与评测，国内外已经形成多种在线工具与平台，但其设计目标与研究需求之间仍存在系统性差距。第一类是面向 C 端用户的在线分离服务，例如 LALAL.AI、Moises 以及 Spleeter Web 等。此类系统通常提供一键式推理分离流程，用户上传音频即可获得结果；但其核心能力更偏向消费级体验，往往难以满足研究场景中的多模型同台对比、客观指标的可复现计算以及基于专家认知的主观质量评估与统计分析需求。第二类是开源命令行工具/推理库，如 Spleeter、Demucs 与 Open-Unmix 等，它们为研究者提供模型权重与推理接口，具备一定可扩展性；但这些工具通常缺乏统一的任务编排与结果管理机制，且难以将主观评分纳入同一评测工作流。第三类是学术评测工具包，如 museval 与 mir_eval 等，主要面向客观指标计算；其优势在于指标透明与实现规范，但通常不提供面向协作的 Web 界面与主观评分机制，也缺少将主观经验用于后续算法优化的闭环流程。第四类为通用音频编辑软件（如 Audacity、Adobe Audition 等），其主要面向后期处理而非面向算法评测，缺乏面向多算法并行对比与质量统计的体系化能力。尽管部分研究/数据平台（例如 MVSEP 等）能够提供基于 SDR 等客观指标的评测与排行榜，但总体上仍以客观指标为主，缺少将专家主观感知系统性纳入分析与反馈的机制。

​	因此，现有系统在算法可扩展性（新模型接入与多模型对比不便）、评测完整性（主客观评估割裂）、协作便利性（缺乏多专家评分与统计机制）以及结果可复现性（样本管理、版本与配置追溯不规范）方面仍存在不足。上述问题共同制约了研究者对 MSS 算法“为什么好、为什么听起来不稳、如何据此改进”的持续验证与迭代。

​	针对上述瓶颈，本文提出以 MSS 算法对比与算法优化为主体、以主客观联合评估（专家反馈闭环）为关键机制的研究方案。为支撑平台设计与方法论选择，本文首先对主流 MSS 模型进行横向评估，并以此刻画“客观—主观”落差在声源维度上的具体表现。本文选取四类代表性方法作为评估对象：MDX23C、Demucs4HT、Band Split RoFormer 与 SCNet。它们分别对应不同的神经网络建模范式：MDX23C通常采用以谱表示为核心的分离策略；Demucs4HT在 U-Net 式结构中引入混合 Transformer 以增强全局建模能力；Band Split RoFormer通过频段分割与 RoFormer 类 Transformer 结构捕获跨频带依赖；SCNet则强调谱域特征的结构化建模（包括通道/分支协同等机制）。在公开基准上，这些算法在不同声源上展现出相对优势，并在推理效率（模型规模、计算复杂度、运行时延/资源消耗）方面呈现显著差异。需要强调的是，即便部分模型在客观指标上能够达到较高水平甚至领先，仍可能在主观听感方面表现不一致，表现为声部泄漏、瞬态模糊和高频伪影等感知问题在某些曲风或编配条件下更为突出。该现象表明：仅依赖客观指标进行算法筛选与优化，难以为感知质量改进提供足够直接、稳定的优化信号，从而构成阻碍领域持续推进的关键障碍。

​	基于以上分析，本文进一步构建 AudioLab 平台，目标在于实现 MSS 的统一任务管理、客观指标计算与专家主观评价的协同工作流，并通过主客观数据的相关性分析，将专家经验转化为可量化的优化依据。具体而言，系统为多算法并行对比提供统一接入方式，为每个评测样本生成可追溯的客观指标（如 SDR/SI-SDR 等）与主观质量评分记录；随后利用主客观关联分析为后续模型优化指明方向，使“高听感质量”在优化过程中具备显式约束。与此同时，在算法层面本文提出基于 SCNet 框架并结合注意力机制与 LoRA 微调的新的音源分离方案，以在保持推理可用性的前提下提升主观感知质量。
