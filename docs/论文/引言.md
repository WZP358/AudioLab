# 引言

## 1.1 研究背景与意义

音乐源分离（Music Source Separation, MSS）旨在将混合音频信号分解为若干独立的语义声部（如人声Vocals、鼓Drums、贝斯Bass、其他伴奏Other等），是音频信号处理与音乐信息检索领域的核心任务之一。该技术在智能编曲、音频后期制作、音乐教育、版权保护及音乐信息检索等场景中具有广泛的应用价值[1-3]。

近年来，深度学习技术的快速发展显著推动了音乐源分离性能的提升。基于深度神经网络的方法在公开数据集（如MUSDB18[4]）上的客观评价指标（如信号失真比SDR、尺度不变信号失真比SI-SDR等）持续刷新纪录，部分模型在特定声部上的SDR已突破10 dB[5-7]。然而，在实际应用场景中，研究者与从业者普遍观察到”客观指标优异但主观听感欠佳”的现象：同一模型在不同音乐风格、不同编配密度的曲目上常出现声部泄漏（source leakage）、瞬态响应模糊（transient smearing）、高频伪影（high-frequency artifacts）等感知质量问题[8-10]。这一现象表明，单纯依赖客观指标难以全面评估算法在真实应用中的实际性能，主观听感评估在算法优化与模型选择中具有不可替代的作用。

尽管学术界已认识到主客观联合评估的重要性，但现有研究多将二者割裂处理：客观指标计算依赖命令行工具或评测脚本，主观评分则通过离线听音实验完成，二者之间缺乏系统化的关联分析机制。这种评估范式不仅增加了研究成本，也限制了主观反馈对算法优化的指导作用。因此，构建一个集成多算法对比、主客观联合评估、专家协作评分及结果可视化分析于一体的系统化平台，对于推动音乐源分离技术的实用化进程具有重要意义。







目前国内外已有一些音乐源分离相关的在线工具和平台，但多存在以下局限：

(1) **面向C端用户的在线分离服务**：如LALAL.AI[1]、Moises[2]、Spleeter Web[3]等，主要提供单一算法的在线分离功能，用户上传音频后获得分离结果，但不支持多算法对比、不提供客观指标计算，也不具备专家评分与统计分析能力，难以用于研究场景。

(2) **开源命令行工具**：如Spleeter[4]、Demucs[5]、Open-Unmix[6]等，提供了模型推理脚本，但缺乏统一的任务管理、结果可视化和评分机制，研究者需要手动编写脚本管理输入输出、计算指标、整理评测数据，工程门槛较高。

(3) **学术评测工具包**：如museval[7]、mir_eval[8]等，专注于客观指标计算，但不提供Web界面、不支持多用户协作、不具备主观评分功能，且需要研究者自行管理音频文件与参考音频的对应关系。

(4) **音频处理平台**：如Audacity、Adobe Audition等专业音频软件虽然功能强大，但主要面向音频编辑而非算法评测，不支持批量任务管理、多算法并行对比和评分统计。

综上所述，现有系统在**算法可扩展性**（难以快速接入新模型）、**评测完整性**（主客观评估割裂）、**协作便利性**（缺乏多用户评分机制）和**结果可复现性**（样本管理不规范）方面存在不足。





为解决该问题，本文提出一种以音源分离神经网络的算法对比和算法优化为主体、以主客观联合评估（基于专家反馈闭环）为关键机制的研究方案：在神经网络模型层面，本文提出基于Scnet、注意力机制和LoRA微调技术的新的音源分离方案，，在主客观评估层面，系统引入专家主观评估与客观评估数据进行相关性分析，，使主观经验能够直接影响后续优化方向，以数据驱动优化
