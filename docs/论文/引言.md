	音乐源分离（Music Source Separation, MSS）旨在将混合音频分解为若干独立的语义声部（如 Vocals、Drums、Bass、Other），广泛应用于智能编曲、音频编辑、音乐信息检索和音乐教育等领域。近年来，深度学习技术驱动的 MSS 在公开数据集上的客观指标（如 SDR、SI-SDR等）持续提升，但在实际应用中仍存在“指标好看、听感不稳”的问题：同一模型在不同曲风、不同编配密度下常出现声部泄漏（source leakage）、瞬态响应模糊（transient smearing）或高频伪影（high-frequency artifacts)等感知质量问题。由此可见，单一依赖客观指标难以全面评估算法模型的实际性能。

​	围绕 MSS 的应用与评测，国内外已提出多类相关系统与工具。根据功能定位的不同，大致可分为以下几类：（msst）

（1）面向终端用户的在线分离平台  
	典型代表包括 LALAL.AI[1]、Moises[2] 以及 MVSEP[3] 等。此类平台通常提供一键式分离服务，支持用户上传音频并快速获得分离结果，其中部分平台还集成多种模型以供选择。然而，该类系统主要面向消费级应用场景，缺乏统一的评测标准与实验可复现机制，难以支持多模型系统化对比分析及主观评价研究。

（2）开源分离工具与模型库  
	代表性方法包括 Spleeter[4]、Demucs[5] 以及 Open-Unmix[6] 等。这类工具为研究者提供模型实现及推理接口，具备较强的灵活性与可扩展性。但其主要聚焦算法层面，缺乏统一的任务管理与实验组织能力，同时难以将主观听感评价纳入标准化评测流程。

（3）学术评测工具包  
	在客观评估方面，museval[7] 与 mir_eval[8] 等工具被广泛应用于 SDR 等指标计算。这类工具具有实现规范、结果可复现等优点，但通常缺乏可视化界面及多用户协作机制，尤其不支持主观评价数据的结构化采集与分析。

（4）综合评测与展示平台  
	部分在线平台（如 MVSEP[3]）虽提供多模型评测与排行榜功能，但整体仍以客观指标为主，缺乏主客观评估融合机制。

​	综上所述，现有系统在多模型统一管理、主客观评估融合以及评测流程可复现性等方面仍存在不足，难以支撑对“模型性能—感知质量”关系的系统性分析。因此，有必要构建一个集成多模型对比、客观指标计算与主观评价的统一评测平台。

​	针对上述问题，本文提出一种面向音乐源分离任务的主客观协同评估方法，并设计实现了统一的评测平台 AudioLab。该平台支持多模型并行对比、客观指标自动计算及专家主观评分的协同分析，从而构建完整的评测闭环。在此基础上，本文选取 MDX23C、Demucs4HT、Band Split RoFormer 及 SCNet 等代表性模型进行对比分析，以探讨不同建模范式在客观指标与主观听感之间的差异表现。

​	进一步地，本文结合主客观评价结果，对模型在不同声源维度上的性能差异进行分析，并尝试将专家主观反馈转化为可量化的优化信号。在此基础上，提出一种基于 SCNet 的改进方法，通过引入注意力机制及 LoRA 微调策略，在保证推理效率的前提下提升分离结果的感知质量。

本文的主要贡献如下：（1）分析了音乐源分离任务中客观指标与主观听感之间的不一致问题；（2）设计并实现了支持主客观协同评估的统一平台；（3）探索了结合主观反馈的模型优化方法；（4）提出用于可解释分析的重叠一致性辅助度量（WOC/SOC），将波形/频谱重叠现象数字化以支持主客观差异解释。
