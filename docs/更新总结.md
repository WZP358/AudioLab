#### 1.2 核心改进
- 严格按照 Vincent et al. (2006) 公式实现
- 完整的误差分解：`ŝ = s + e_spat + e_interf + e_artif`
- 投影算子实现：`_projection_operator()`
- 支持同时评估多个源（2-4个）

#### 1.3 API 接口
- **新增**: `POST /api/tasks/{task_id}/objective-metrics-batch`
  - 一次性上传所有源的金标准参考
  - 返回每个源的 SDR/SIR/SAR/ISR
  - 计算平均值并写入任务记录

- **保留**: `POST /api/tasks/{task_id}/objective-metrics`
  - 单源评估（两源假设）
  - 向后兼容

#### 1.4 指标说明
| 指标 | 公式 | 含义 |
|------|------|------|
| SDR | `10 log10(‖s‖² / ‖e_spat + e_interf + e_artif‖²)` | 整体失真 |
| SIR | `10 log10(‖s + e_spat‖² / ‖e_interf‖²)` | 干扰抑制 |
| SAR | `10 log10(‖s + e_spat + e_interf‖² / ‖e_artif‖²)` | 伪影抑制 |
| ISR | `10 log10(‖s‖² / ‖e_spat‖²)` | 空间失真 |

## 技术细节

### 投影算子实现
```python
def _projection_operator(signal, reference, eps=1e-12):
    """
    投影算子 Π{ref}(signal)
    
    单个参考：P_ref(signal) = <signal, ref> / ‖ref‖² * ref
    多个参考：使用最小二乘 lstsq(reference, signal)
    """
    if reference.ndim == 1:
        alpha = np.dot(signal, reference) / (np.dot(reference, reference) + eps)
        return alpha * reference
    else:
        coef, *_ = np.linalg.lstsq(reference, signal, rcond=None)
        return reference @ coef
```

### 误差分解流程
```python
# 1. 投影到目标源子空间
s_target = _projection_operator(est, ref_target)

# 2. 计算空间失真
e_spat = s_target - ref_target

# 3. 投影到所有源子空间
s_all = _projection_operator(est, ref_matrix)

# 4. 计算干扰
e_interf = s_all - ref_target - e_spat

# 5. 计算伪影
e_artif = est - ref_target - e_spat - e_interf
```

## 使用示例

### 客观指标计算
```bash
curl -X POST "http://localhost:8000/api/tasks/123/objective-metrics-batch" \
  -H "Authorization: Bearer TOKEN" \
  -F "vocals_ref=@vocals_ref.wav" \
  -F "drums_ref=@drums_ref.wav" \
  -F "bass_ref=@bass_ref.wav" \
  -F "other_ref=@other_ref.wav"
```

### 主观评分提交
```bash
curl -X POST "http://localhost:8000/api/scores/batch" \
  -H "Authorization: Bearer TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "task_id": 123,
    "algorithm": "MDX23C",
    "scores": [
      {"stem_name": "Vocals", "quality": 85, "interference": 78, "artifacts": 82},
      {"stem_name": "Drums", "quality": 72, "interference": 68, "artifacts": 75},
      {"stem_name": "Bass", "quality": 68, "interference": 65, "artifacts": 70},
      {"stem_name": "Other", "quality": 60, "interference": 58, "artifacts": 62}
    ]
  }'
```
